Connect your Infomaniak Ecosystem

To enable Single Sign-On (SSO) and integrate kChat, kMeet, and kDrive, you need to register Digitana as an application in your Infomaniak Manager.

Step 1: Create Application

  1. Go to Infomaniak Manager.
  2. Navigate to API & Developers -> OAuth2 Applications.
  3. Click Create Application.
  4. Enter Name: Digitana.
  5. Enter Redirect URI: {{ redirect_uri }}
  6. Select Scopes: User (Profile), kDrive, kChat, kMeet.

Step 2: Initialize Services

Create the default Infomaniak service entries in the database so they appear in the connection menu.
