# digitana – Projektdokumentation

digitana ist ein hybrides, sozialarbeiterisch fundiertes Unterstützungsangebot
zur digitalen Teilhabe älterer Menschen in der Schweiz, entwickelt unter dem
Dach von **IT-Matters**.

> **Leitsätze:** «Technik ist Werkzeug – Beziehung ist Wirkungsträger» ·
> «Digitalisierung ist Teilhabe – nicht nur Effizienz»

Diese Dokumentation folgt der im Auftragsprompt festgelegten Struktur. Sie ist
Obsidian-kompatibel (Markdown, YAML-Header). Der aktuelle Bearbeitungsstand
entsteht in **Phase 0 (Bestandsaufnahme und Konsolidierung)**.

## Statuskennzeichen

Aussagen und Entscheidungen sind konsistent gekennzeichnet:

| Kennzeichen | Bedeutung |
|---|---|
| `[VERBINDLICH]` | Ausdrücklich entschieden, gilt bis zum Widerruf |
| `[BESTÄTIGTER PROJEKTSTAND]` | Belegter, geprüfter Ist-Zustand |
| `[HISTORISCHE PLANUNG]` | Aus früheren Unterlagen, vor Übernahme neu zu prüfen |
| `[FACHLICHE EMPFEHLUNG]` | Empfehlung der Fachinstanz, noch nicht entschieden |
| `[ARBEITSANNAHME]` | Reversible Annahme, um weiterzuarbeiten |
| `[OFFENE ENTSCHEIDUNG]` | Blockierend oder wichtig, Entscheid ausstehend |
| `[SPÄTERE OPTION]` | Bewusst zurückgestellt |
| `[VERWORFEN]` | Geprüft und abgelehnt |
